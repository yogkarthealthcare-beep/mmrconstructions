Important Note

Direct: जिस associate ने customer को सीधे refer करके plot sell कराया, उसे मिलने वाला commission।

Upline: Direct associate के ऊपर MLM network में मौजूद sponsor/parent associates को level के अनुसार मिलने वाला commission।

Example: A → B → C → Customer अगर C ने customer को plot बेचा, तो C को Direct commission, B को Upline Level 1 और A को Upline Level 2 commission मिलेगा।

Level Depth: यह बताता है कि commission network में ऊपर किस level के associate को मिलेगा।
