1. GOLDEN RULE OF AUTO-DETECTION

The software recognizes allotable units strictly by LAYER NAME and CLOSED POLYLINE geometry, NOT by line colour. If the layer is correct and the polyline is closed with a number inside, detection is 100% automatic. Colours are recommended for drafting consistency.

4. Geometry & Boundary Rules
  • One Unit = ONE Closed LWPOLYLINE / POLYLINE: Open polylines will NOT be detected. Use AutoCAD command PEDIT > Multiple > Join > Close.
  • No Separate LINEs or HATCH Only: Units must not be formed by loose LINE entities or pure solid HATCH without a boundary polyline.
  • Explode Blocks / XREFs: If units are grouped in blocks or external references, EXPLODE them before exporting.
  • Bulge Arcs are Supported: Curved boundary segments (arcs in polyline) are automatically converted into smooth polygons. Avoid SPLINE or ELLIPSE entities for unit boundaries.
  • No Overlaps or Self-Intersections: Units must not overlap each other, and boundary contours must not form "bow-tie" intersections.
  • Clean Layer Separation: Roads, parking slots, green belts, legend boxes, and title blocks must stay on their respective support layers.
5. Unit Numbering & Text Rules
  • Layer PLOT_NUMBERS: Each unit MUST have exactly one TEXT or MTEXT element on the layer PLOT_NUMBERS.
  • Text Position Inside Boundary: The text insertion point must lie strictly inside the closed polyline (near the center).
  • Prefix Standards: Plots: numbers only (e.g. 1, 2, 101). Do not write "Plot 1". Malls: M-1, M-2... Restaurants: R-1, R-2... Hospitals: H-1... Schools: S-1...
  • Global Uniqueness: Numbers must be unique across the entire site plan.
  • Annotations on TEXT_LABELS: Road names, dimensions, and legend labels must be on TEXT_LABELS or DIMENSIONS.
6. File Export Rules
  • Format: ASCII DXF (AutoCAD 2010 / AC1024 or newer).
  • Units: Feet or Metres (1:1 real-world scale).
  • Model Space: All geometry in Model Space.
  • Purge: Run PURGE command to remove unused layers and blocks.
7. Pre-Submission Checklist
  • Closed polylines count = TEXT on PLOT_NUMBERS count.
  • Zero open polylines on unit layers.
  • No unnumbered unit or number outside a unit.
  • Zero duplicate numbers across site.
  • Saved as clean ASCII DXF.
8. For Developers: Adding New Unit Types

To introduce any new allotable unit type in the future:

  1. Open src/app/shared/unit-types.config.ts
  2. Add a new object to UNIT_TYPES (e.g. CLUBHOUSE, HOTEL, OFFICE).
  3. Define its cadLayer, numberPrefix, aciColor, and fillRgb.

The extractor, layer mapping UI, filter chips, drawing toolbar, auto-numbering, and guideline texts update automatically from this single config.
